## Entry

> Earth, 4/5: They charge for water but give you as much gravity as you want, which feels like an oversight.

106 characters.

## How it works

`main.py` writes the entry verbatim to `/output/entry.txt` (UTF-8, no
trailing newline), then reads the file back and exits with an error if
even one character differs. It reads no external files and makes no
network calls.

Run it with:

```
python3 main.py
```

## Files

- `main.py` — writes the entry to `/output/entry.txt`
- `prompt.txt` — the entry text, verbatim
- `LICENSE` — MIT
- `HANDOFF.md` — method, character count, and verification results
- `.makefun/owner.json` — bounty owner wallet
